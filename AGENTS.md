# ResumeLens Development Guidelines

## Project Goal

ResumeLens is a production-style resume analysis web application.
The project is being developed as a learning project.

## Development Principles

- Prefer simple solutions over unnecessary complexity.
- Explain important architectural decisions before implementation.
- Keep responsibilities separated between layers.
- Do not introduce dependencies without a clear reason.
- Do not modify unrelated files.
- Do not delete existing code or files unless explicitly requested.
- Keep changes small and understandable.
- Follow existing project conventions.
- Write tests for important functionality.
- Never hard-code secrets or credentials.
- Never invent resume metrics or achievements.

## AI Coding Guidelines

- Explain what you intend to change before making substantial changes.
- Clearly identify files that will be modified or created.
- Avoid large unrelated refactors.
- Ask before introducing major technologies or dependencies.
- After making changes, summarize what changed and why.
